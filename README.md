# 茶叶盲评一致性分析

不同质检员对同批茶反复盲评打分、匿名样杯事后可能更正批号的场景下，对**评员个人偏差**、
**批内一致性**与**评级一致性**进行本地分析的网页应用。仅使用 Node.js 内置模块，无任何第三方依赖，不接外部服务。

## 启动

```bash
node server.js          # 兼容入口
# 或
node src/server.js      # 实际实现
```

- 端口读取环境变量 `PORT`（默认 3000），例如 `PORT=8080 node server.js`
- 仅绑定 `127.0.0.1`，不对本机以外暴露
- 打开 http://127.0.0.1:3000

## 测试

```bash
node --test             # Node 测试运行器默认发现 test/ 下的用例
npm test                # 等价：node --test test/*.test.js
```

30 个用例，覆盖正常结果与异常结果（数据不足、非法输入、404/400、路径穿越防护等）。

## 页面上的三个操作（可在同一次会话内连续完成并前后核对）

1. **分析原盲评数据**：可切换「成对分数」或「按盲评轮次调整」两种偏差算法。
2. **更正一只样杯**：选择杯号与新批号后提交，页面并排展示修订前后受影响的评分与批次聚合。
3. **查看评级一致性**：逐杯、逐批、评员两两的评级一致率与分歧杯。

所有业务结果区都带 `data-evidence-result` 属性（`bias`、`batch-consistency`、
`rating-agreement`、`correction`、`revision-badge`），便于自动化核对操作前后的内容变化。

## 统计口径（关键设计决策）

### 1. 重复打分不是独立样本

同一只杯、同一位评员在多个盲评轮次的打分属于**重复测量**。所有分析先按
`(cupId, evaluatorId)` 折叠为一个观测（分数取轮次均值，评级取众数），
再做杯间/评员间统计；折叠前后的记录数都会在页面和 API 中明示。
评员对同一杯的多轮波动单独作为「评员重复性（within-evaluator SD）」指标报告。

### 2. 评员个人偏差的两种算法

- **成对分数（默认）**：评员在某杯折叠分 − 该杯所有评员共识分，再对杯取平均。
  正值表示系统性偏高。同时给出评员两两的共同杯数与平均差。
- **按盲评轮次调整**：先扣除每轮相对总均值的轮次效应
  （`adjusted = score + 总均值 − 轮均值`），再折叠计算。
  - 若每个「杯×评员」组合在每一轮都有打分（真正的平衡设计），轮次效应在成对差中
    自动抵消，全精度结果与成对法严格相等，页面显式说明；
  - 若存在缺轮（非平衡设计），返回 `balanced=false` 并说明已做轮次校正。

### 3. 批内一致性

- 杯级：共识分、杯内标准差（总体 SD）、极差、评级一致率；
- 批级：平均杯内 SD、**ICC(A,1)**（双向随机、绝对一致、单评员信度），
  只用该批所有评员均打分的完整杯，完整杯不足 2 只时返回 `null` 并说明原因；
- 评员重复性：同一评员对同一杯多轮打分的自身 SD，再对杯平均；无多轮数据时标记「数据不足」。

### 4. 样本不足一律显式标记

覆盖率不足半数、共同杯少于 3、单评员的杯、完整配对不足、无重复测量等情况，
都以 `状态=数据不足/覆盖偏低` + 文字警告呈现，绝不输出无意义的精确指标。

### 5. 样杯更正（不改原始评分）

更正只修改「杯 → 批号」映射：

- 原始打分记录一条不删，重复测量结构不变；
- 每次更正生成带序号的修订日志，保存修订前/后映射快照与**全部受影响评分记录快照**；
- 更正响应同时返回修订后的完整分析，前端并排对照修订前后；
- 杯级共识分与评员偏差不随更正变化（评分未变），变化的是批次级聚合与评级的批次归属；
- 「重置为初始样例」可随时回到初始数据并清空修订日志。

## 目录结构

```
server.js              # 兼容入口（node server.js）
src/
  server.js            # 内置 http 模块服务、路由、静态文件、JSON API
  analysis.js          # 纯函数：折叠/偏差/轮次调整/ICC/一致性
  store.js             # 内存存储与杯批映射修订（快照、校验、重置）
  sample-data.js       # 本地样例：5 杯 × 3 评员 × 2 轮（平衡设计）
public/
  index.html  styles.css  app.js   # 原生前端，无外部依赖
test/
  analysis.test.js  store.test.js  http.test.js
```

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/analysis?method=paired\|round-adjusted` | 完整分析 |
| GET | `/api/state` | 当前杯批映射与修订计数 |
| POST | `/api/corrections` | 更正杯批号，返回修订条目 + 修订后分析 |
| GET | `/api/revisions`、`/api/revisions/:id` | 修订日志与快照 |
| POST | `/api/reset` | 恢复初始样例 |
